# LeoSim Module for ns-3

This module provides functionality for simulating Low Earth Orbit (LEO) satellite networks in ns-3.

## Features

- Core LeoSim model implementation
- Helper classes for easy setup
- Example programs
- Unit tests

## Building

```bash
./ns3 configure --enable-examples --enable-tests
./ns3 build
```

## Running Examples

```bash
./ns3 run leosim-example
```

## Running Tests

```bash
./test.py -s leosim
```

See the module documentation in `doc/leosim.rst` for detailed information.
